# ChippyDip

**Dip into the chips. Make something loud.**

ChippyDip is an original, open-source retro-console-inspired instrument project. Our first milestone is a playable NES-style browser lab, followed by a native standalone instrument and VST3 build.

Project status: initial scaffold in progress. Browser synthesis is hardware-inspired, not yet verified as cycle-accurate emulation.

All code and patches will be our own; no ROMs or copyrighted game samples are included.
